# REQUIREMENTS-M6 — 管理页「账号详情」窗口（一键复制接入信息）

> 自包含需求书：不依赖对话上下文。冲突时以仓库现状为准，直接实现，不要提问、不要中断。

## 背景

现在建完账号后，管理页只能看到 AK 与 SK（掩码/显示），**没有一个「详情」窗口**把接入所需的全部信息
集中展示并可一键复制。用户接其它 App（思源笔记、rclone、各类 S3 客户端）时要自己拼端点、区域、
寻址方式、示例命令 —— 摩擦大且容易填错。

目标：账号列表每行有「详情」入口；点开后一个窗口把接入信息全列出来，每项可一键复制；
**新建账号成功后自动打开这个窗口**。

## 1. 详情窗口内容（全部可复制）

| 项 | 说明 |
|---|---|
| Endpoint | 对外访问地址。**必须运行时推导**：优先取请求的 `X-Forwarded-Proto` + `X-Forwarded-Host`/`Host`（本服务跑在反向代理后）；若配置了环境变量 `OBJBOX_PUBLIC_ENDPOINT` 则以其为准。**仓库内不得出现任何真实域名或 IP** |
| Bucket | 该账号的默认桶名；并列出该账号当前实际存在的桶（见 §2 接口） |
| Access Key | 可一键复制 |
| Secret Key | 默认掩码显示；点「显示」后才出现复制按钮（掩码状态下复制按钮禁用） |
| Region | `us-east-1`（与实现一致，可复制） |
| Addressing | `Path-style`（必须用路径寻址，文案说明这一项在客户端里要选 Path-style） |
| 示例配置 | 纯文本块，整块可复制：① rclone 一行命令 ② 通用 S3 客户端字段清单（Endpoint / AK / SK / Bucket / Region / Path-style 六项） |
| 说明 | 一句话：「桶不存在会自动创建，Bucket 那栏随便填或填账号名即可」 |

复制按钮一律走浏览器剪贴板；复制成功给轻量反馈（按钮文案短暂变化即可，不要弹窗、不要 emoji）。

## 2. 后端

- 新增只读接口 `GET /api/admin/accounts/{name}/buckets`：返回该账号当前桶名数组（走该账号 `Backend.ListBuckets`）。
  鉴权、错误体形状、审计风格与现有 `/api/admin/accounts*` 保持一致；**不得返回 SK 明文**。
- 账号列表/详情响应补齐详情窗口需要的字段（`bucket`、`autoCreateBucket` 等；M5 已加的字段直接复用）。
- 现有接口路径、方法、鉴权、错误体形状**一律不变**。

## 3. 前端（`web/`）

- 账号列表每行新增「详情」按钮 → 打开模态窗口；新建账号成功后自动打开（且不影响原有创建流程）。
- 窗口内所有值均可选中复制；SK 掩码逻辑与列表一致（复用现有掩码/显示实现，不要另写一套）。
- 样式沿用现有页面（直角、发丝线、单琥珀点缀）；**不新增依赖、不引图标库、不用 emoji**；文案中文、克制、
  不写技术说明性文案。
- 前端构建产物仍走 `//go:embed all:dist`；`make build` 顺序保持「先构建前端再 `go build`」。

## 4. 文档

- `README.md`（中英双语）：一句话说明管理页可一键复制接入信息。
